# Between us

A minimal, single-page site made for a personal conversation. It is built with
plain HTML, CSS, and JavaScript, so it can be published directly with GitHub Pages.

## Preview locally

Open `index.html` in a browser, or run any simple static-file server from this
folder.

## Publish on GitHub Pages

Push these files to a GitHub repository, then open **Settings → Pages** and choose
**Deploy from a branch**. Select the branch containing the files and the `/ (root)`
folder.
